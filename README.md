# Dinosaur demo

Standalone interactive dinosaur viewer with six models, animation controls, and animated model previews.

## Deploy on Vercel

Import this GitHub repository. Choose the Other framework preset and keep the root directory at the repository root. The included vercel.json disables installation/build steps and serves this directory directly.

## Updating

Replace index.html with the latest Dinosaur-Demo.html export from the source project, then commit and push. Vercel automatically redeploys connected repositories.

The HTML embeds the models, textures, scripts, and previews; no additional asset folders are required. Initial download is approximately 73.5 MiB.

Stegosaurus is the second gallery entry after T-Rex, with 11 imported actions (action 7 is the source T-pose).

Triceratops is the third gallery entry. Its replacement FBX supplies 10 actions; action 8 is the source T-pose.
